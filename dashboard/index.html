📘 Announcement Variables Guide

Use these in the message above the embed, embed author, title, description, and footer. Preview shows sample values; the bot substitutes real member/server details when posting.

User

{user}Member mention.
{user.mention}Member mention.
{user.username}Member's username.
{user.tag}Member's Discord tag / username display.
{user.id}Member's Discord ID.
{user.avatar}Member's avatar URL. Use in Thumbnail URL, Image URL, or Footer icon URL.

Server

{server}Server name.
{server.name}Server name.
{server.id}Server's Discord ID.
{server.icon}Server icon URL.

Channels

{#channel-name}Channel mention. Replace channel-name with the exact channel name, for example {#📜・rules}. The preview shows a Discord-style channel label.

📘 Leveling Variables Guide

Use these placeholders in your level-up message, embed author, title, description, and footer.

Levels

{level}Display the user's current level.
{xp.current}Display the user's current XP.
{xp.required}Display the XP required to reach the next level.
{xp.total}Display the user's total XP.
{messages}Display the number of messages the user has sent.

User

{user}Mention the user or display their username.
{user.username}Display the user's username.
{user.id}Display the user's Discord ID.
{user.avatar}Display the user's avatar URL.
{user.mention}Mention the user.

Server

{server.name}Display the server name.
{server.id}Display the server's Discord ID.
{server.icon}Display the server icon URL.
